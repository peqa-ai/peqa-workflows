# Ruta de ejecución

Antes de preguntar, delegar o gestionar PRs, lee las ramas pertinentes de [herramientas del entorno](../../../references/runtime-tools.md). Es la referencia compartida para T3, Codex y Claude Code: selección nativa/T3, preguntas de hijos, espera y cancelación, y propiedad del watcher.

Para revisión con el modelo preferido carga [el adaptador de peqa-revisa](../../peqa-revisa/references/reviewers.md). Para implementar conserva el motor actual salvo una selección autorizada; el fallback específico de revisión no se aplica a toda tarea.
