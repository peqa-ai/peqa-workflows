# Ruta de ejecución

Antes de preguntar, delegar o gestionar PRs, lee las ramas pertinentes de [herramientas del entorno](../../../references/runtime-tools.md). Es la referencia compartida para T3, Orca, Codex y Claude Code: detección y precedencia de hosts, selección entre mecanismo nativo, T3 u Orca, preguntas de hijos, espera y cancelación, y entrega de PRs.

Para revisión con el modelo preferido carga [el adaptador de revisa](../../revisa/references/reviewers.md). Para implementar conserva el motor actual salvo una selección autorizada; el fallback específico de revisión no se aplica a toda tarea.
